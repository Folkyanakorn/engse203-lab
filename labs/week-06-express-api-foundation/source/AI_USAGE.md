## ครั้งที่ 1

**ถามอะไร**
- CP08 ลองเทสแล้วคำร้องที่เพิ่มหายไปเกิดจากอะไร

**AI ตอบว่าอย่างไร (สรุปสั้น)** 
- สาเหตุหลักๆ มักจะเกิดจาก 2 กรณี คือ "เซฟไฟล์ไม่สำเร็จตั้งแต่แรก" หรือ "ตอนเปิดเซิร์ฟเวอร์โหลดไฟล์ไม่ขึ้น"
    - จุดที่ 1: เช็คว่าไฟล์ถูกสร้างขึ้นมาจริงๆ หรือไม่
    - จุดที่ 2: เช็คการใส่ async / await ใน Controller

**ใช้ส่วนไหน / แก้เองตรงไหน** 
- CP08 แก้ตรง function create , function remove ลืมใส่ async และ await และเรียก persist()

**เข้าใจโค้ดที่ได้มาไหม** [] เข้าใจทั้งหมด [x] เข้าใจบางส่วน [] ยังไม่เข้าใจ
